# Mana Books

Web-novel and ebook sources for [Mana](https://github.com/Mana-iOS). Every source opens in
Mana's book reader: web novels come through as clean HTML chapters, and ebook sites hand over
the EPUB, PDF or text file itself.

## Installing

**[Add Mana Books to Mana](https://mana-ios.github.io/add-repo/?url=https%3A%2F%2Fmana-core.github.io%2Fbooks&name=Mana%20Books)** to get every source, or tap **Install** next to a single
source below. Both open Mana, which shows what it's about to add and asks first.

To add it by hand, paste this address under **Discover → Repositories → Add Repo**:

```
https://mana-core.github.io/books
```
